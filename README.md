### 🚀 Featured projects

#### 🐟 [Autonomous Robotic Fish](https://github.com/J-rowland/Robotic-Fish-Project)
A two-joint robotic fish that sees and swims on its own.
- Computer vision with **OpenCV** and an exploreHD underwater USB camera
- Servo control ported from Arduino to **embedded C** using `lgpio` on a **Raspberry Pi 5**
- Pi runs as a Wi-Fi hotspot for remote access; network-based servo control in progress

#### 📈 Foresight: Prediction Market
A prediction market app built in **React**.
- Real **order book engine** with limit orders
- Market settlement mechanics and state persistence

#### 🎛️ Self-Balancing Triple Pendulum *(in progress)*
A triple inverted pendulum balanced by a controller I'm designing from scratch.
- Simulation-first: equations of motion with **SymPy**, **LQR** control design before hardware

#### 🤖 Reinforcement Learning from Scratch
Working through RL fundamentals.
- Trained a **PPO** agent on CartPole with Stable-Baselines3 and Gymnasium
- Next up: implementing **REINFORCE** from scratch
